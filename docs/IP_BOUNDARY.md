# Original Expression / IP Boundary

Ganjumanji must remain an independently designed DTF Genetics game.

## Allowed inspiration level

General adventure-game ideas such as exploring ruins, collecting keys/relics, avoiding hazards, opening gates, solving environmental challenges, and progressing through chambers are genre-level concepts. Implementation must use DTF-original names, layout, rules combinations, visual treatment, text, characters, symbols, and assets.

## Do not copy

Do not reproduce or closely trace another game's:

- board/path geometry;
- map/chamber layout;
- named characters or creature designs;
- logos, title treatments, fonts used as identifying trade dress, or packaging;
- card/event text;
- story scenes or dialogue;
- distinctive props or puzzle sequences;
- music/sound recordings;
- source code or unlicensed art/assets.

## Current vertical slice provenance

The Temple Atrium environment, Seed Sigil objective structure, Resolve system, spore-vent hazards, Canopy Gate, game text, procedural player, temple geometry, UI, and code in this repository were authored for this project. The first playable intentionally uses code-built primitive geometry and standard Three.js materials rather than third-party models or textures.

## Future asset intake

Every production model, texture, sound, font, icon, and animation must have one of these provenance states before release:

- created specifically for DTF Genetics;
- generated/commissioned with rights suitable for commercial web use;
- licensed from a source whose license is recorded and compatible with use;
- public-domain/CC0 with provenance recorded.

Unknown-license assets stay out of the production build.
